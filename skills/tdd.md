# Test-Driven Development (TDD) Workflow

Every implementation task must follow this cycle:

1. **RED:** Write a failing unit test for the specific requirement.
2. **GREEN:** Write the minimal amount of code to make the test pass.
3. **REFACTOR:** Clean up the code while ensuring tests remain green.

**Mandatory:** Do not write functional code without a corresponding test unless it is purely UI/styling (which should still be verified visually or via component rendering tests).
