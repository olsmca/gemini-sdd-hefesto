# Vercel & React Modern Best Practices

Follow these guidelines for rapid frontend iteration:

1. **Next.js App Router:** Standard for all frontend React projects.
2. **Server Components:** Prioritize performance, data fetching, and SEO.
3. **Tailwind CSS / Vanilla CSS:** Build interfaces using modern, clean design systems.
4. **Server Actions:** Simplify data mutations and communications.
5. **A11y:** Ensure interactive elements are accessible according to the project's standard.
