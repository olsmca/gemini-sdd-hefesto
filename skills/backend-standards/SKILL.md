# Backend Engineering Standards

Choose the right technology for the iteration:

1. **Go:** Best for high-performance, concurrent microservices.
2. **FastAPI:** Ideal for rapid AI-augmented backends and Python integration.
3. **Node.js (TypeScript):** Seamless integration with JS/TS frontend.

## Core Principles
- **Clean Architecture:** Separate domain logic, services, and models from HTTP/DB adapters.
- **REST/GraphQL/gRPC:** Define clear API contracts in the technical spec.
- **TDD:** Write tests before logic to ensure stability.
- **Security:** Follow OWASP guidelines for input validation, sanitization, and auth.
