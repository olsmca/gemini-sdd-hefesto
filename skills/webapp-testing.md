# Webapp Testing Standards

Ensure robustness with a multi-layered testing strategy:

1. **Unit Testing:** Use appropriate framework runner (Vitest/Jest for React, native go test, pytest for FastAPI).
2. **Component Testing:** Use testing libraries to assert frontend UI behaviors.
3. **E2E Testing:** Playwright or Cypress for critical user flows.
4. **Coverage:** Target 80%+ coverage on core business logic.
