# Clean Architecture & Code Scalability

Maintain high-quality code structure following these principles:

1. **Separation of Concerns:** Keep business logic independent of UI and Frameworks.
2. **Domain-Driven Design (Lite):** Organize folders by feature/domain (e.g., `features/auth`, `features/billing`).
3. **SOLID Principles:**
   - Single Responsibility.
   - Open/Closed.
   - Liskov Substitution.
   - Interface Segregation.
   - Dependency Inversion.
4. **DRY & KISS:** Don't repeat yourself, but keep it simple. Avoid over-engineering.
5. **Modularization:** Prefer small, focused modules over monolithic files.
